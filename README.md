# Savor: Arkansas Restaurant Map

Live site: https://jcredibletech.github.io/savor/

A static site (Leaflet with marker clustering) that maps every food place OpenStreetMap lists in Arkansas: 3,391 places in 22 cuisine groups. Places that have been researched carry a green, yellow, red, unknown or closed rating, with the reason and links to every source.

- `index.html`, `assets/`: the site, with no build step and no API keys.
- `data/*.json`: generated by `build_data.py` from the Savor workspace: the OSM dataset, the Census ZCTA centroids and the rating runs (`../runs/*.json`, merged by OSM id with the newest run winning). The rating progress counter comes from `../runs/_progress.json`.
- `publish.sh`: rebuilds the data and pushes it in one command.

Data: © OpenStreetMap contributors (ODbL), via the Overpass API. ZIP centers come from the US Census 2020 ZCTA Gazetteer. Basemap: HOT style, hosted by OpenStreetMap France. Ratings never invent anything: every claim links to its source, and anything unverified is labeled unknown.
